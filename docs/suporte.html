Suporte

Canal de suporte do FREE AGENT para ChatGPT e do cliente Windows.

Usar no ChatGPT

  1. Entre na sua conta no painel e gere um código de vinculação.
  2. Baixe e extraia o cliente Windows, execute INICIAR_FREE_AGENTE_REMOTO.cmd e digite o código.
  3. No ChatGPT, adicione o plugin FREE AGENT e entre com a mesma conta.
  4. Coloque os arquivos que quer trabalhar em Documentos\FREE AGENTE\area-de-trabalho e deixe o cliente aberto.

Problemas comuns

  • "Computador desconectado": abra o cliente FREE AGENT no PC vinculado.
  • Limite diário atingido: o plano gratuito tem 300 ações por dia.
  • Excluir conta ou dados: abra um pedido abaixo; atendemos em até 30 dias.

Fale conosco

Abra uma issue no GitHub com a versão do Windows e os passos para reproduzir. Nunca inclua senhas, códigos de vinculação nem arquivos pessoais. Falhas de segurança: use o relato privado.
