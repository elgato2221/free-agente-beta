Suporte

Este é o canal de suporte do beta 0.2.0 para Windows 64 bits.

Comece aqui

  • Extraia todo o ZIP antes de executar.
  • Dê duplo clique em INICIAR_FREE_AGENTE.cmd e mantenha a janela aberta.
  • Clique em COPIAR_LINK.cmd para copiar o endereço de conexão.
  • Cadastre o endereço em um cliente MCP compatível (quando seu plano permitir).
  • Coloque apenas arquivos que deseja editar na pasta autorizada em Documentos.

Dúvidas e erros

Abra uma issue pública descrevendo o erro, versão do Windows e passos para reproduzir. Nunca inclua senhas, URLs completas do MCP nem arquivos pessoais.

Segurança

Reporte falhas de segurança pelo canal privado do GitHub, não em Issues públicos.

Integridade do arquivo

O SHA-256 do ZIP está disponível no mesmo release, em um arquivo .sha256. Compare após o download se desejar.
