Privacidade

Última atualização: 26/10/2026. Esta é a política do beta portátil do FREE AGENTE distribuído por este repositório independente.

Quais dados são tratados

O agente funciona localmente no Windows. Você escolhe quais arquivos de texto serão colocados na pasta autorizada. Para processar solicitações, o cliente de IA conectado envia pedidos ao agente por meio de um túnel Cloudflare. O conteúdo dos arquivos lidos pode ser enviado ao cliente de IA para formular as respostas.

Onde ficam seus dados

Os arquivos são mantidos na pasta autorizada no seu computador. O software grava uma credencial de conexão e o último endereço temporário na pasta oculta .free-agente dentro da instalação do programa. Não há cadastro central obrigatório nem coleta de pagamentos neste beta.

Terceiros e retenção

O tráfego passa pelo Cloudflare Tunnel e pelo cliente de IA escolhido por você. Esses serviços possuem políticas e práticas próprias. O software não transmite telemetria própria a um banco de dados central nesta versão. Não prometemos sigilo de ponta a ponta ou retenção zero por terceiros.

Controle e exclusão

Feche o aplicativo para encerrar o túnel. Exclua a pasta de instalação para descartar a credencial e o histórico de link; exclua os arquivos da pasta autorizada somente se desejar removê-los do seu computador. Isso não apaga automaticamente conteúdo que o cliente de IA possa ter registrado.

Suporte e solicitações

Use o suporte no GitHub para dúvidas gerais. Não publique dados pessoais, senhas ou links MCP em Issues públicos. Para reportar problemas de segurança, use relato privado.
