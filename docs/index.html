Sem instalador complexo

Três passos para começar.

O cliente já inclui o Node.js. Você só precisa de Windows, de uma conta FREE AGENT e do ChatGPT.

01 • VINCULAR

Conecte seu PC

Entre no painel, gere um código de vinculação, extraia o ZIP e execute INICIAR_FREE_AGENTE_REMOTO.cmd com o código.

02 • CONECTAR

Adicione no ChatGPT

Instale o plugin FREE AGENT no ChatGPT e entre com a mesma conta. A conexão usa OAuth: nenhum link ou token para copiar.

03 • USAR

Trabalhe nos arquivos

Coloque arquivos de texto em Documentos\FREE AGENTE\area-de-trabalho, deixe o cliente aberto e peça ao ChatGPT para listá-los, lê-los ou editá-los.

O que funciona hoje

Comece pelo essencial.

Leitura de arquivos

Veja a estrutura da pasta e peça explicações e revisões dos seus arquivos de texto.

Edição e criação

O ChatGPT grava arquivos de texto na pasta autorizada, como notas, documentação e scripts (incluindo C# para Unity).

Análise em lote

Com o Code Mode, o ChatGPT combina várias leituras em uma só etapa, em ambiente isolado e somente leitura.

Transparência do beta: o FREE AGENT não executa comandos, não compila projetos, não instala programas e não acessa nada fora da pasta autorizada. Gravar um arquivo pode substituir o conteúdo anterior: mantenha cópias de segurança.

Perguntas frequentes

O que você precisa saber.

Meu PC precisa ficar ligado?

Sim. O ChatGPT fala com o nosso servidor, que repassa o pedido ao cliente aberto no seu PC. Sem o cliente aberto, as ferramentas avisam que o computador está desconectado.

O FREE AGENT guarda meus arquivos?

Não. O conteúdo passa pelo servidor só em trânsito e não é gravado. Veja a política de privacidade.

Preciso pagar tokens de API?

Não. A IA é a do seu ChatGPT; o FREE AGENT só fornece o acesso aos arquivos.

Como desligo o acesso?

Feche o cliente, revogue o computador no painel ou desconecte o plugin no ChatGPT.

Já há assinatura Pro?

Não. Nesta versão beta não existe cobrança.
